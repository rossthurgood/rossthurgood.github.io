# Ross Thurgood's Portfolio Website

## About The Project

This repository contains the source code for my personal portfolio website, available at [rossthurgood.co.uk](https://rossthurgood.co.uk).

The website was designed and developed to showcase my work in graphic design, digital media, and website development. It acts as a professional digital portfolio where I present projects, demonstrate technical and creative skills, and document my progression throughout my Creative iMedia course.

The portfolio was created as part of my BTEC Creative iMedia Practice coursework, focusing on:

* Graphic design
* Website development
* Digital graphics
* Image manipulation
* User experience and responsive design

The project was built primarily using:

* HTML
* CSS
* JavaScript

## Project Goals

The primary purpose of this project was to create a professional portfolio website that:

* Promotes my digital media and graphic design work
* Demonstrates technical website development skills
* Presents completed projects clearly and professionally
* Creates a recognisable personal brand
* Appeals to employers, recruiters, and university admissions

The website was designed around a clean and modern visual style using consistent branding, responsive layouts, strong imagery, and intuitive navigation. 

---

## Design Process

Throughout development, I researched modern website trends and professional portfolio layouts to help shape the final design. My research identified several important design conventions used across successful websites, including:

* Fixed navigation headers
* Responsive layouts
* Strong visual hierarchy
* Consistent colour schemes
* Interactive user elements
* Large visual content areas

These influenced the structure and appearance of the final website. 

The final design uses:

* A blue/green gradient colour palette
* Large visual content sections
* Animated backgrounds
* Hover effects
* Responsive navigation
* Consistent branding using my custom logo

## Responsive Design

The website was designed with responsive behaviour to support:

* Desktop computers
* Laptops
* Tablets
* Smaller mobile screens

CSS media queries were used to adapt:

* Navigation layouts
* Text sizing
* Content spacing
* Flexbox structures
* Interactive menus

---

## Key Technical Features

### Animated Backgrounds

The website uses CSS keyframe animations to create shifting gradient backgrounds for a more modern visual appearance.

### Rotating Text Animation

JavaScript is used on the homepage to rotate descriptive words dynamically within the welcome section.

### Responsive Navigation

A collapsible navigation system was developed for smaller screen sizes using JavaScript and CSS media queries.

### Interactive Gallery

The portfolio section includes image galleries and hover effects designed to improve user engagement.
