Yes — you can absolutely use those CDN imports of GSAP and ScrollTrigger to control your timeline with scrub, but you must register the plugin before using it, and you must attach the timeline to a ScrollTrigger instance.

Here’s the short version:

Yes, your CDN imports work fine — you just need to call gsap.registerPlugin(ScrollTrigger) and attach a ScrollTrigger to your timeline.

✅ How to make your timeline scrub with ScrollTrigger
You already have:

js
import gsap from 'https://cdn.jsdelivr.net/npm/gsap@3.12.5/index.js';
import { ScrollTrigger } from 'https://cdn.jsdelivr.net/npm/gsap@3.12.5/ScrollTrigger.js';
Now add:

js
gsap.registerPlugin(ScrollTrigger);
Then attach ScrollTrigger to your timeline:

js
const timeline = gsap.timeline({
  scrollTrigger: {
    trigger: "#yourScrollContainer",   // element that controls scroll
    start: "top top",
    end: "bottom bottom",
    scrub: 1,                          // <— enables scrubbing
    markers: true                      // optional for debugging
  }
});
And your animation stays exactly the same:

js
timeline
  .to(ship.scale, { x: 1, y: 1, z: 1, ease: "none" }, 0)
  .to(earth.position, { x: -15, ease: "none" }, 0)
  .to(earth.scale, { x: 0.3, y: 0.3, z: 0.3, ease: "none" }, 0)
  .to(planet1.position, { x: 0, ease: "none" }, 0)
  .to(planet1.position, { x: -15, ease: "none" }, 0.75)
  .to(planet2.position, { x: 0, ease: "none" }, 1.5)
  .to(planet2.position, { x: -15, ease: "none" }, 2.25);
🧠 Why your original code didn’t scrub
GSAP timelines don’t automatically connect to scroll — you must explicitly create a ScrollTrigger instance and bind it to the timeline.

Asteroid generator (unique shapes + light grey)
js
function createAsteroid(size) {
  const geo = new THREE.IcosahedronGeometry(size, 1);

  // deform vertices for uniqueness
  const pos = geo.attributes.position;
  for (let i = 0; i < pos.count; i++) {
    const nx = (Math.random() - 0.5) * size * 0.6;
    const ny = (Math.random() - 0.5) * size * 0.6;
    const nz = (Math.random() - 0.5) * size * 0.6;
    pos.setXYZ(
      i,
      pos.getX(i) + nx,
      pos.getY(i) + ny,
      pos.getZ(i) + nz
    );
  }
  pos.needsUpdate = true;
  geo.computeVertexNormals();

  const mat = new THREE.MeshStandardMaterial({
    color: 0xbfc1c2, // light grey
    roughness: 1,
    metalness: 0
  });

  return new THREE.Mesh(geo, mat);
}
Asteroid belt generator (ring around “sun”)
js
function createAsteroidBelt({
  count = 500,
  radius = 18,
  width = 8,
  minSize = 0.05,
  maxSize = 0.3,
  y = 0
}) {
  const group = new THREE.Group();

  for (let i = 0; i < count; i++) {
    const size = THREE.MathUtils.lerp(minSize, maxSize, Math.random());
    const asteroid = createAsteroid(size);

    const angle = Math.random() * Math.PI * 2;
    const dist = radius + (Math.random() - 0.5) * width;

    asteroid.position.set(
      Math.cos(angle) * dist,
      y + (Math.random() - 0.5) * 1.5,
      Math.sin(angle) * dist
    );

    asteroid.rotation.set(
      Math.random() * Math.PI,
      Math.random() * Math.PI,
      Math.random() * Math.PI
    );

    group.add(asteroid);
  }

  return group;
}

⭐ 4. Insert the belt into your GSAP timeline
You already created a gap using:

js
.to({}, { duration: 2 })
Now animate the belt inside that gap:

js
timeline
  .to({}, { duration: 2 }) // asteroid belt window

  // fade + rotate belt as ship approaches
  .from(asteroidBelt.position, { x: "+=5", duration: 2, ease: "none" }, "<")
  .from(asteroidBelt.children, {
    opacity: 0,
    duration: 1.5,
    stagger: 0.002
  }, "<")
  .to(asteroidBelt.rotation, { y: "+=0.5", duration: 2, ease: "none" }, "<");
This makes the belt appear naturally as the ship enters the region.
